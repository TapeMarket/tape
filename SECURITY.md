# Security

Tape has not received an audit from an outside firm. The README describes the trusted price
signer, operator roles, direct exits, settlement queue and immutable contracts. Review fixes in
source may require a new deployment; source changes do not modify contracts already on Ethereum.

For a possible loss of funds, accounting error, authorization bypass, price manipulation or key
exposure, use this repository's **Security → Advisories → Report a vulnerability** option if
private vulnerability reporting is available. If the option is unavailable, open an issue
requesting a private contact channel without including exploit instructions or sensitive data.

A private report should identify the affected source revision or deployed address, the impact,
and a local reproduction or test. Never include private keys, authentication tokens or personal
data. Do not test an exploit against funded production accounts.

Ordinary UI bugs and non-sensitive development issues can be filed as public issues. No bounty
or response deadline is promised.
